# extr-me-droite-blocker
permet de bloquer les compte d'extrême droite qui retweet des tweet 



Comment ca marche, 

Crée un dossier Extrême Droite blocker, coller les fichiers dans le dossier 
Ouvrez google chrome et coller : chrome://extensions/ et cliquez sur :  Charger l'extension non empaquetée
Mettez le dossier : Extrême Droite blocker

cliquez sur le tweet d'extrême droite que vous voulez wipe cliquez sur : View post activity puis sur repost.

Ouvrez ensuite l'extension et cliquez sur collecter et bloquer
